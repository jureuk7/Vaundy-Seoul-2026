# 응원가이드 — 깃허브에 올리기

## 1. 저장소에 올릴 파일

```
index.html            ← 응원가이드 본체
design.css            ← 화면 디자인과 글꼴 설정
fonts/                ← 오프라인에서도 쓰는 Pretendard · Gmarket Sans 글꼴
DESIGN.md             ← 화면 디자인 원칙
sw.js                 ← 오프라인 캐시 담당
manifest.json         ← 앱 이름·아이콘·색상
icon-192.png          ← 홈 화면 아이콘
icon-512.png          ← 스플래시 / 큰 아이콘
apple-touch-icon.png  ← 아이폰 홈 화면 아이콘
images/               ← 기존 포스터 이미지 폴더 (poster.jpg 등) — 함께 올려 주세요
```

전부 **같은 폴더(저장소 최상단)** 에 두어야 합니다. 경로를 상대경로(`./`)로 잡아 두었기 때문에
`https://아이디.github.io/저장소이름/` 형태에서도, 나중에 도메인을 붙여도 그대로 동작합니다.

폰트 재배포 조건은 `fonts/OFL-Pretendard.txt`와 `fonts/OFL-GmarketSans.txt`에 적었습니다.

## 2. 깃허브 페이지 켜기

1. 깃허브에서 새 저장소를 만들고 위 파일을 올립니다 (드래그 앤 드롭으로도 됩니다)
2. 저장소 → **Settings** → 왼쪽 메뉴 **Pages**
3. Source 를 **Deploy from a branch**, Branch 를 **main / (root)** 으로 두고 Save
4. 1~2분 뒤 `https://아이디.github.io/저장소이름/` 주소가 생깁니다

깃허브 페이지는 https 로 제공되므로 오프라인 캐시가 바로 동작합니다.

## 3. 확인하기

- 폰에서 주소를 열고 몇 초 기다립니다 (이때 캐시가 저장됩니다)
- 비행기 모드로 바꾼 뒤 새로고침 → 가사·공연정보가 그대로 열리면 성공
- 안드로이드: "홈 화면에 설치" 안내가 뜹니다
- 아이폰: 공유 버튼 → **홈 화면에 추가** (앱 안에도 안내가 한 번 뜹니다)

홈과 각 화면 상단의 `다크 모드` / `라이트 모드` 버튼으로 화면 색을 바꿀 수 있습니다. 처음에는 기기 설정을 따르고, 직접 고른 뒤에는 선택을 기억합니다. 홈 포스터는 어느 모드에서도 원래의 어두운 분위기를 유지합니다. 곡 화면 아래 알약형 바에서 이전 곡, 현재 곡 목록, 다음 곡으로 이동할 수 있습니다.

도쿄 셋리스트는 스포일러 경고 화면에서 보기 방식을 직접 선택해야 표시됩니다.
곡명만 보는 방식은 공연 순서를 섞어 표시합니다. 랜덤 보기에서 공연 순서로 바꾸려면 확인 단계에서 다시 `순서 공개`를 눌러야 합니다. 홈이나 곡 화면에서 셋리스트로 다시 들어가면 경고 화면부터 시작합니다.

## 4. ★ 내용을 고쳐서 다시 올릴 때

가사를 고치거나 화면을 바꿔 다시 올릴 때는 **`sw.js` 상단의 `CACHE_VERSION` 숫자를 꼭 올려 주세요.**

```js
const CACHE_VERSION = "v1";   //  →  "v2" 로 변경
```

이 숫자가 그대로면 이미 방문한 사람 폰에는 예전 내용이 계속 보입니다.
숫자를 올리면 다음 접속 때 새 파일을 받고, 화면 아래에
"새 버전이 준비됐어요 · 새로고침" 안내가 떠서 바로 갱신할 수 있습니다.
